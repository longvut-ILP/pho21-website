# Phở 21 — Restaurant Website

Website for **Phở 21**, 11005 Fuqua St #110, Houston, TX 77089 — (713) 910-7006.

Built and maintained by **The Houston IT Solutions**.

## About

A single-page static site (`index.html`) — no build step required.

- Three languages: English (default), Tiếng Việt, Español
- Weekly specials, full menu, gallery, guest reviews, Google Maps, tap-to-call
- Order Online section with DoorDash / Uber Eats placeholders (activate by
  replacing the two `order-btn` links with the restaurant's store URLs)

## Deployment

Deployed on Vercel. Every push to `main` deploys automatically.
